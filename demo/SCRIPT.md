# Budget Buddy: demo script (self-recorded)

Recorded by Avie as a screen recording with my own voice, as the hackathon rules require (no AI video or AI voice). Target 3 to 4 minutes. Live app: https://budget-buddy-one-mu.vercel.app

Before recording: open the live app in two windows (one normal, one private/incognito), close other tabs, turn on Do Not Disturb.

| # | On screen | What I say |
|---|-----------|------------|
| 1 | Home page | Hi, I'm Avie, and this is Budget Buddy, built on Mozilla's Otari. It's AI chat for families and classrooms, where every kid or student gets their own weekly AI budget, like pocket money. |
| 2 | Point at the two doors | Most families share one AI account. One key, one bill, and no way to say Ada gets this much and Tobi gets that much. Budget Buddy fixes that. Kids come in with a code, grown-ups sign up here. |
| 3 | Create free account: name, email, password | I'll sign up as a parent. Anyone can create a free group: a name, an email and a password. |
| 4 | Dashboard, add "Ada", cap 0.50 | This is my dashboard. I'll add Ada with a weekly cap of fifty cents. She gets a six-letter join code straight away. I'll copy it. |
| 5 | Private window, paste code, Start | Now I'm Ada on her own device. No email, no password, just the code. She sees how much budget she has left and when it refills. |
| 6 | Tap a suggestion, or ask "Explain photosynthesis like I'm 10" | She asks a homework question. The answer comes from Mistral Small, an open-weight model, through Otari. Under every answer you can see exactly what it cost, using the cost Otari sends back. |
| 7 | Ask one more question | It's a tiny fraction of a cent, so fifty cents a week goes a long way. |
| 8 | Back to dashboard | Back on the parent side, Ada's spend and chat count have already gone up. It updates live. |
| 9 | Tap Pause, then Ada sends a message | If homework is done, I tap Pause. Her next message is blocked before it reaches the model, so it costs nothing. The same happens when she hits her weekly cap, and caps refill every Monday. Resume brings her back. |
| 10 | README on GitHub, Otari features table | How it uses Otari: every chat goes through Otari's chat completions. On hosted otari.ai, requests are tagged per member and the app enforces each cap from Otari's cost. With a self-hosted Otari, each member gets their own virtual key and a weekly Otari budget, so Otari itself enforces the cap. |
| 11 | Home page | Budget Buddy is open source and free to try at the link in the README. Thanks for watching. |

Tips: talk a little slower than normal, it's fine to pause and keep going, and trim mistakes afterwards. Export as MP4, upload to Google Drive (or YouTube unlisted) and set "anyone with the link".
